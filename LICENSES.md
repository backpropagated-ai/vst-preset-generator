## Surge XT (GPL-3.0) — ported format code

This project's Surge XT `.fxp` writer
([`preset-core/src/writers/surge.rs`](./preset-core/src/writers/surge.rs)) and
its embedded init-patch parameter table
([`preset-core/src/writers/surge_init_data.rs`](./preset-core/src/writers/surge_init_data.rs))
are **derived from the Surge XT source tree**, which is licensed under
**GPL-3.0-or-later**:

> Surge XT — a free and open source hybrid synthesizer, built by the Surge Synth
> Team. <https://github.com/surge-synthesizer/surge>
> Copyright 2018–2024, various authors (see the Surge XT repository).
> Released under the GNU General Public License v3 or later.

Specifically, the FXP container layout, the `sub3` patch-header struct, and the
patch-XML schema were reproduced by reading:

- `src/common/SurgeSynthesizerIO.cpp` (`savePatchToPath`, `loadPatchByPath`)
- `src/common/SurgePatch.cpp` (`save_patch`, `save_xml`, `load_xml`)
- `src/common/PatchFileHeaderStructs.h` (`fxChunkSetCustom`, `patch_header`)
- `src/common/Parameter.cpp`, `src/common/FilterConfiguration.h`,
  `src/common/SurgeStorage.h`, and `libs/sst/sst-filters/.../FilterConfiguration.h`
  (value encodings and enum orderings)

The embedded parameter default table (`surge_init_data.rs`) is extracted from
the Surge XT 1.3.4 factory template patch `patches_factory/Templates/Init Saw.fxp`
(Surge Synth Team content, distributed as part of the GPL-3.0 Surge XT release;
nothing from `patches_3rdparty/` is used). It can be regenerated with
[`scripts/regen_surge_init.py`](./scripts/regen_surge_init.py) against an
installed Surge XT.

Reusing this GPL-3.0 code is the reason this project is GPL-3.0. No Surge XT
binaries or presets are bundled.

## Web (in-browser generator)

The static browser generator under [`docs/app/`](./docs/app/) runs entirely
client-side. It uses one WebAssembly module (`docs/app/pkg/`) built from this
project's own `preset-wasm` crate, plus two third-party components loaded **at
runtime from public CDNs** — neither is bundled or redistributed in this repo:

| Component | License | How it's used |
|-----------|---------|---------------|
| [`@huggingface/transformers`](https://github.com/huggingface/transformers.js) (transformers.js) | Apache-2.0 | Imported at runtime from the jsDelivr CDN; runs the embedding model on the WASM backend (no WebGPU required). |
| [`Xenova/all-MiniLM-L6-v2`](https://huggingface.co/Xenova/all-MiniLM-L6-v2) (quantized) | Apache-2.0 | ~23 MB sentence-embedding model (default); weights stream from the Hugging Face CDN at runtime and are cached by the browser. |
| [`Xenova/bge-small-en-v1.5`](https://huggingface.co/Xenova/bge-small-en-v1.5) (quantized) | MIT (BAAI bge) | ~32 MB embedding model — optional "better English matching" choice. |
| [`Xenova/multilingual-e5-small`](https://huggingface.co/Xenova/multilingual-e5-small) (quantized) | MIT (intfloat e5) | ~113 MB multilingual embedding model — optional choice for non-English prompts; used with the e5 `query:` prefix. |
| [`HuggingFaceTB/SmolLM2-360M-Instruct`](https://huggingface.co/HuggingFaceTB/SmolLM2-360M-Instruct) (q4f16) | Apache-2.0 | ~260 MB instruct model — smallest WebGPU choice that fills the parameter JSON directly (falls back on degenerate output). |
| [`onnx-community/gemma-3-1b-it-ONNX`](https://huggingface.co/onnx-community/gemma-3-1b-it-ONNX) (q4f16) | Gemma Terms of Use | ~0.8 GB instruct model — strongest WebGPU direct-generation choice. Weights stream from the HF CDN at runtime; not bundled or redistributed here. |

All are Apache-2.0 or MIT, which are GPL-3.0-compatible. Because they are fetched from
their own CDNs at runtime rather than copied into this repository, no third-party
code or model weights are redistributed here. The `docs/app/pkg/` WebAssembly
build is generated by `wasm-pack build --target web` from `preset-wasm` and is
checked in only so GitHub Pages can serve it statically; it can be regenerated at
any time and contains only this project's GPL-3.0 code.

The prompt→parameters "anchor bank" ([`docs/app/anchors.js`](./docs/app/anchors.js))
is hand-authored from first-principles sound design and contains **no third-party
preset content**.

## Not bundled (deliberately)

- **No third-party preset files.** Presets under the parent repo's `presets/`
  directory (Vital, Serum, Surge, Phase Plant, …) are third-party content and
  are **not** included or redistributed. The Vital JSON format was learned by
  reading the structure of two or three sample files only; no preset content was
  copied. Any example presets shown in the README are generated on the fly.
- **No Anthropic API keys or credentials.**
